# Foco Diário 🎯

Projeto em Python criado para ajudar na organização das prioridades do dia e reduzir a procrastinação.

A proposta é ir além de uma lista comum de tarefas: o usuário define suas principais prioridades em ordem de importância, e o programa ajuda a manter o foco no que deve ser executado primeiro.

## 💡 Ideia

Muitas vezes temos várias tarefas para realizar e acabamos sem saber por onde começar. O Foco Diário parte de uma ideia simples: limitar o dia a três prioridades principais e executá-las de forma organizada.

## 🚧 Versão 0.1 — Em desenvolvimento

A primeira versão será executada no terminal e permitirá:

- Definir três prioridades para o dia
- Organizar as prioridades por ordem de importância
- Marcar prioridades como concluídas
- Visualizar o progresso do dia
- Identificar qual é o próximo foco

## 🐍 Conceitos utilizados

O projeto está sendo desenvolvido conforme avanço nos meus estudos de Python.

Nesta primeira versão serão utilizados:

- Variáveis
- Entrada e saída de dados
- Listas
- Estruturas condicionais
- Estrutura de repetição `while`

## 🔮 Evoluções planejadas

Futuramente, o projeto poderá incluir histórico de produtividade, armazenamento de tarefas, interface gráfica e recursos de inteligência artificial para auxiliar na organização das prioridades.
